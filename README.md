# Foodie's Restaurant Website

## Overview

Developed a responsive restaurant website using HTML, CSS, JavaScript, and Bootstrap. The website provides an interactive user experience with menu browsing, food gallery, customer reviews, contact form, and shopping cart functionality.

## Features

- Responsive design for desktop and mobile devices
- Interactive navigation menu
- Food menu with search functionality
- Shopping cart with quantity management
- Food gallery section
- Customer reviews section
- Contact form with validation
- Special offers section
- Smooth scrolling navigation
- Bootstrap integration

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Bootstrap Icons

## Skills Gained

- Front-End Development
- Responsive Web Design
- DOM Manipulation
- JavaScript Programming
- User Interface Design
- Bootstrap Framework
