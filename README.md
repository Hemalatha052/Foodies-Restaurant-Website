# Foodie's Restaurant Website

## Overview

Developed a responsive restaurant website using HTML, CSS, JavaScript, and Bootstrap. The website provides an engaging user experience with menu browsing, food gallery, customer reviews, and contact sections.

## Features

- Responsive design
- Interactive user interface
- Food menu section
- Food gallery
- Customer reviews
- Contact page
- Menu search functionality

## Technologies Used

- HTML
- CSS
- JavaScript
- Bootstrap

## Skills Gained

- Front-End Development
- Responsive Web Design
- User Interface Design
- JavaScript Programming
